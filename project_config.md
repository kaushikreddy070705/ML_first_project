# Project Configuration

## Project Name

Customer Churn Prediction & Retention Analytics System

## Problem

A telecom company wants to identify customers who are likely to churn based on available customer, service, and account information.

## Machine Learning Problem

Supervised Binary Classification

## Target Variable

Churn

## Classes

- Yes = Customer churned
- No = Customer did not churn

## Initial Features

Potential input features include:

- Customer demographics
- Tenure
- Services
- Contract information
- Payment information
- Monthly charges
- Total charges

## Initial Models

1. Logistic Regression
2. Random Forest
3. XGBoost

## Evaluation Metrics

- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC
- Confusion Matrix

## Application

The final system will provide customer churn predictions through an API and an interactive dashboard.

## Planned Backend

FastAPI

## Planned Frontend

Streamlit

## Project Limitations

This is a portfolio and learning project based on a historical dataset. Model predictions should not be interpreted as guaranteed future customer behavior or causal explanations of why a customer churns.
