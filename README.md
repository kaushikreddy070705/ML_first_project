# Customer Churn Prediction & Retention Analytics System

An end-to-end Machine Learning Engineering project for predicting customer churn using XGBoost, FastAPI, Streamlit, Docker, and Docker Compose.

## Project Status

Complete.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- FastAPI
- Streamlit
- Docker
- Docker Compose
- Git/GitHub

## Architecture

Customer Data  
↓  
Data Preprocessing  
↓  
Feature Engineering  
↓  
ML Model  
↓  
FastAPI  
↓  
Streamlit Dashboard

## Machine Learning

Models explored:

- Dummy Baseline
- Logistic Regression
- Random Forest
- XGBoost

The final system uses a tuned XGBoost model for churn prediction.
